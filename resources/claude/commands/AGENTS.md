# Commands (Claude Code)

Claude Code slash commands live one level deeper than OpenCode: under an `osx/` subdirectory.

## Layout

```
commands/
└── osx/
    └── <name>.md             # Auto-generated from resources/opencode/commands/osx-<name>.md
```

The full set of command files lives at `resources/claude/commands/osx/`.

## Mirror generation

The Claude mirror is generated by `mise run sync-mirrors`. **Do not edit Claude command files directly** — every generated file carries an `# AUTO-GENERATED` header. To change a command:

1. Edit `resources/opencode/commands/osx-<name>.md`.
2. Run `mise run sync-mirrors` to regenerate.
3. Commit both.

## Frontmatter

Claude Code commands accept the full frontmatter spec. The mirror inherits the OpenCode frontmatter (with platform-specific tokens substituted):

```yaml
---
description: <one-line purpose>
license: MIT
[compatibility: <optional>]
[allowed-tools: <optional>]
---
```

The `name:` field on Claude commands comes from the frontmatter of the file (used by Claude Code's slash-command resolver). The mirror script preserves the frontmatter verbatim.

## Filename vs Name

| Filename | Frontmatter `name` | Slash invocation |
|----------|--------------------|------------------|
| `phase0.md` | `osx-phase0` | `/osx-phase0` |
| `review.md` | `osx-review` | `/osx-review` |

The filename omits the `osx-` prefix; the frontmatter `name:` field carries it.

## Conventions

- The Claude mirror is **always** generated from OpenCode; never hand-edit Claude commands.
- Phase commands (`phase0` … `phase6`) are the only entry points the orchestrator uses; the dispatch table is the same.
